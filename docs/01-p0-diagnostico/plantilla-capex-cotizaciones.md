# Plantilla CAPEX y cotizaciones — P0

## Objetivo

Ordenar cotizaciones para completar CAPEX preliminar por categorías antes de evaluar P1 preliminar.

## Categorías

- Pollonas.
- Galpón.
- Bodega.
- Agua.
- Solar.
- Equipamiento.
- Logística.
- Mano de obra.
- Imprevistos.

## Campos mínimos de cotización

| Campo | Descripción |
|---|---|
| Proveedor | Nombre del proveedor |
| Fecha | Fecha de cotización |
| Ítem | Producto o servicio |
| Cantidad | Número requerido |
| Unidad | Unidad de medida |
| Precio unitario | Precio CLP unitario |
| Total | Cantidad x precio unitario |
| Observación | Condiciones, despacho, validez |
| Estado | pendiente / cotizado / descartado |

## Cómo comparar cotizaciones

- Usar misma unidad de medida.
- Registrar fecha.
- Separar precio producto de transporte.
- Indicar si incluye IVA o despacho.
- No mezclar estimaciones con cotizaciones reales.
- Mantener evidencia del proveedor.

## Resultado esperado

CAPEX preliminar por categoría, aún sin ser presupuesto definitivo.
