# Resumen ejecutivo P0 — base 500 aves

## Resumen

Gallinero Nacho pasa a evaluar como escenario base **500 aves totales**. El escenario 648 queda como histórico/referencial. El proyecto sigue en P0 con estado amarillo.

## Datos clave

- Aves actuales: 148.
- Producción promedio: 132 huevos/día.
- Postura promedio: 89.2%.
- Venta actual: 28 bandejas/semana.
- Objetivo base 500: 104.1 bandejas/semana estimadas.
- Brecha base 500: 76.1 bandejas/semana.
- Galpón base 500: 72 m² cotizados, $5.547.765, densidad aproximada 7 gallinas/m².
- Agua base 500: 115.7–154.3 L/día estimados.

## Decisión actual

P1 preliminar no habilitado. Compra, construcción e inversión mayor no autorizadas.

## Conclusión

El siguiente paso es levantar evidencia para 500 aves: mercado, CAPEX, flujo, agua, energía, logística y legal/contable.
