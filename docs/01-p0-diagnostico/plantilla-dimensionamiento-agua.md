# Plantilla de dimensionamiento de agua — P0

## Objetivo

Guiar el levantamiento de datos para dimensionar agua en forma preliminar, sin cerrar diseño ni presupuesto.

## Datos base

- Consumo actual: 34 L/día.
- Gallinas actuales: 148.
- Operación proyectada: 648 aves.
- Proyección preliminar: 150–200 L/día.
- Solución conceptual: estanque 1.000 L + bomba.

## Datos a levantar

- Caudal disponible.
- Presión disponible.
- Altura entre estanque y bebederos.
- Ubicación del estanque.
- Tipo de bomba.
- Filtros.
- Fittings.
- Líneas.
- Niples/bebederos.
- Respaldo ante falla.
- Riesgos de humedad.

## Fórmulas simples

```text
consumo_por_ave = consumo_diario / numero_aves
consumo_total_estimado = consumo_por_ave_estimado x aves_proyectadas
autonomia_dias = litros_estanque / consumo_diario_estimado
```

No usar estos resultados como definitivos sin revisión técnica.

## Riesgos a revisar

- Falta de presión.
- Falta de caudal.
- Fugas.
- Bebederos botando agua.
- Humedad dentro del galpón.
- Falta de respaldo.

## Evidencia esperada

Planilla de dimensionamiento, fotos, ubicación propuesta, cotización y observaciones técnicas.
