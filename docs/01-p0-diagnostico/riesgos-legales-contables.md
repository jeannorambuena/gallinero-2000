# Riesgos legales y contables P0 — Proyecto Gallinero Nacho

## Objetivo

Identificar temas legales y contables preliminares que deben revisarse si el proyecto escala, sin presentar conclusiones legales definitivas ni reemplazar asesoría profesional.

## Situación actual

- Falta revisar formalización si el proyecto escala.
- Falta definir registro de ingresos y gastos.
- Falta revisar venta formal a almacenes, minimarket o feria.
- Falta revisar trazabilidad, respaldo documental, impuestos y eventuales exigencias sanitarias/comerciales.
- El diagnóstico corresponde a P0 preliminar, no a asesoría legal definitiva.

## Riesgos si escala

- Mantener venta informal cuando el volumen exige mayor respaldo.
- No contar con registro ordenado de ingresos.
- No respaldar gastos de alimento, envases, medicamentos, transporte o materiales.
- Vender a negocios sin claridad sobre boletas, facturas o documentación requerida.
- No considerar impuestos asociados a mayor volumen de ventas.
- No contar con trazabilidad mínima de producción, ventas y mortalidad.
- Mezclar gastos personales con gastos del negocio.
- No revisar permisos o exigencias aplicables si se vende a terceros o comercios.

## Temas a revisar

- Venta informal vs venta formal.
- Respaldo de ingresos.
- Respaldo de gastos.
- Boletas/facturas si vende a negocios.
- Impuestos.
- Trazabilidad.
- Permisos o exigencias aplicables si escala.
- Registro de inventario, alimento, mortalidad y ventas.
- Separación de gastos personales y del negocio.
- Impacto de vender a terceros o comercios.

## Datos faltantes

- Forma actual de registro de ventas.
- Forma actual de registro de gastos.
- Si existe inicio de actividades o figura formal aplicable.
- Requisitos de almacenes/minimarket para comprar huevos.
- Requisitos para vender en feria.
- Obligaciones tributarias según volumen y canal.
- Requisitos sanitarios o comerciales aplicables.
- Sistema mínimo de trazabilidad.
- Criterio para separar gastos personales y del negocio.

## Criterios mínimos para habilitar P1 preliminar

- Definir cómo se registrarán ingresos y gastos.
- Revisar con contador la forma de operación si escala.
- Revisar requisitos para vender a negocios o feria.
- Identificar documentación mínima necesaria para ventas formales.
- Definir trazabilidad básica de producción, mortalidad, alimento, inventario y ventas.
- Separar gastos personales y del negocio.
- Levantar permisos o exigencias aplicables antes de comprometer inversión.

## Estado

**pendiente.** El bloque legal/contable todavía requiere revisión externa y definición operativa.

## Advertencia

Esto no reemplaza revisión de contador, asesor legal o autoridad competente. Debe usarse solo como diagnóstico preliminar P0.
