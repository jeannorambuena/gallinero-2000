# P0 — Diagnóstico real

## Objetivo
Comprender la operación actual de aproximadamente 300 gallinas.

## Entregables
- diagnóstico productivo;
- diagnóstico económico;
- diagnóstico sanitario;
- diagnóstico constructivo;
- diagnóstico del terreno;
- listado de datos faltantes;
- recomendación de avance o corrección.

## Condición de cierre
No quedan supuestos críticos sin identificar.
