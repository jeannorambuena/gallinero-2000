# Replanteo de escala — escenario base 500 gallinas totales

## Motivo del replanteo

El diagnóstico P0 mantiene como escenario base **500 gallinas totales de operación**. P42 corrige una inconsistencia importante: el escenario principal no es comprar 500 pollonas, sino completar desde las **148 gallinas actuales** hasta el objetivo de **500**.

## Escenario anterior versus escenario base vigente

| Concepto | Escenario anterior/referencial | Escenario base vigente |
|---|---:|---:|
| Aves actuales | 148 | 148 |
| Objetivo usado para evaluar | 648 aves | 500 gallinas totales |
| Interpretación | hipótesis antigua de suma masiva | operación total objetivo |
| Estado | referencia histórica | base decisional vigente |

El escenario de 648 aves no se borra; queda documentado como referencia histórica para auditoría del proceso.
