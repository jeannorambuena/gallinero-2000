# Criterios de no avance — P0

## Objetivo

Definir condiciones sugeridas para detener, pausar o rediseñar el proyecto antes de habilitar P1 preliminar. Estos umbrales son sugeridos y deben revisarse con Jean/Nacho antes de usarse como decisión definitiva.

| Dimensión | Criterio | Umbral o evidencia sugerida | Decisión sugerida | Acción correctiva |
|---|---|---|---|---|
| Comercial | Demanda insuficiente | No se validan clientes/canales para acercarse a 130–135 bandejas/semana | Pausar | Revalidar canales o reducir escala |
| Financiero | Margen insuficiente | Flujo proyectado queda muy ajustado o negativo | Rediseñar | Ajustar escala, precio, costos o canal |
| CAPEX | Inversión incompleta | No hay cotizaciones por categorías críticas | Pausar | Cotizar antes de avanzar |
| Flujo | Flujo incompleto | Faltan costos o ingresos relevantes | Pausar | Completar flujo mensual |
| Agua | Sistema no dimensionado | No se conoce caudal, presión, bomba o respaldo | Bloquear avance | Dimensionar solución completa |
| Energía | Solar no dimensionado | No se conocen watts, batería, paneles o protecciones | Bloquear avance | Dimensionar cargas y cotizar |
| Construcción | Sin alternativa preliminar | No hay croquis, cubicación ni cotización inicial | Pausar | Preparar alternativa y materiales |
| Logística | Acceso riesgoso | No se resuelve descarga/acopio/invierno | Rediseñar | Plan de transporte y acopio |
| Legal/contable | Formalización no revisada | No se sabe cómo vender formalmente si escala | Pausar | Revisar con contador/asesor |
| Sanitario | Riesgos ambientales activos | Humedad, calor o bebederos sin corrección | Rediseñar | Corregir ventilación/cama/agua |

## Conclusión

Si uno o más criterios críticos se mantienen sin resolver, P1 preliminar debe seguir no habilitado.
