# Plantilla de croquis terreno 19 x 7 m

## Objetivo

Levantar un croquis simple del terreno inmediato disponible para evaluar ubicación, acceso, riesgos y alternativas preliminares sin diseñar todavía el galpón.

## Datos a levantar

| Dato | Descripción | Evidencia |
|---|---|---|
| Medidas | Largo y ancho real del área 19 x 7 m | Medición en terreno |
| Galpón actual | Ubicación y orientación | Croquis / foto |
| Bodega | Ubicación y medidas | Croquis / foto |
| Acceso | Entrada de camioneta/camión | Croquis / foto |
| Pendiente | Dirección y nivel aproximado | Observación |
| Zonas de barro | Sectores críticos en invierno | Foto / observación |
| Drenaje | Hacia dónde corre el agua | Croquis |
| Acopio | Lugar posible para materiales | Croquis |
| Descarga | Punto posible de descarga | Croquis |
| Ampliación | Zona potencial futura | Croquis |

## Esquema ASCII simple

```text
NORTE ↑

+-------------------------------------------------+
| Zona potencial / pendiente / drenaje            |
|                                                 |
| [Galpón actual]        [Bodega]                 |
|                                                 |
| Zona acopio               Punto descarga        |
|                                                 |
| Acceso camioneta / camino                       |
+-------------------------------------------------+

Anotar: largo, ancho, pendiente, barro, drenaje y obstáculos.
```

## Reglas

- No convertir este croquis en diseño definitivo.
- Marcar incertidumbres.
- Adjuntar fotos si existen.
- Registrar fecha y responsable.
