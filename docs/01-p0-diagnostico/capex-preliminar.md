# CAPEX preliminar — base 500 aves

## Objetivo

Ordenar el CAPEX preliminar para el nuevo escenario base de 500 aves totales.

## Dato histórico conocido

- 500 pollonas x $8.500 = $4.250.000.

Este dato se conserva como antecedente histórico de precio unitario. Desde el replanteo no significa automáticamente comprar 500 aves adicionales. La estrategia para llegar a 500 aves totales queda pendiente.

## Categorías pendientes

- pollonas/reposición según estrategia;
- galpón;
- bodega/apoyo;
- agua;
- energía solar;
- equipamiento;
- logística;
- mano de obra;
- imprevistos.

## Conclusión

CAPEX total para 500 aves sigue pendiente y no autoriza compra ni inversión.
