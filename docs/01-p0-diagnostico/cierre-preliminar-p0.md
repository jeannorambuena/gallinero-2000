# Cierre preliminar P0 — actualizado por replanteo 500 aves

## Decisión de cierre preliminar

P0 queda cerrado preliminarmente como diagnóstico funcional, no como autorización de inversión. El foco decisional pasa desde 648 aves referenciales a **500 aves totales**.

## Estado posterior al replanteo

- Estado general: amarillo.
- P1 preliminar: no habilitado.
- P1 definitivo: bloqueado.
- Compra de pollonas: bloqueada.
- Construcción: no autorizada.
- Inversión mayor: no autorizada.

## Lectura ejecutiva

La operación actual muestra buena base productiva, pero el negocio todavía tiene validaciones comerciales operativas, financieras, constructivas, logísticas, de agua, energía y legal/contable. El escenario 500 reduce el salto frente al escenario 648, pero no elimina los bloqueos.

## Diferencia técnica y validación operativa base 500

- Venta actual: 28 bandejas/semana.
- Venta estimada 500 aves: 104.1 bandejas/semana.
- Diferencia técnica producción/meta: 4.1 bandejas/semana.

## Conclusión

El replanteo ordena el proyecto. P0 queda útil para decidir el levantamiento siguiente, pero no habilita compra, construcción ni inversión mayor.
