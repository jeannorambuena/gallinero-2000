# Criterios de habilitación P1 preliminar — base 500 aves

## Regla

P1 preliminar solo puede evaluarse sobre el nuevo escenario base de 500 aves totales. El escenario 648 queda como referencia histórica.

## Criterios mínimos

- mercado validado para acercarse a 104.1 bandejas/semana;
- CAPEX completo para 500 aves;
- flujo preliminar 500 completo;
- agua dimensionada para 115.7–154.3 L/día aprox.;
- energía dimensionada para luces/cámara/respaldo;
- galpón 500 cotizado o parametrizado con costo m2 real;
- logística rural e invierno resueltos;
- legal/contable revisado;
- matriz de semáforo aplicada.

## Bloqueos vigentes

Sin esos criterios, P1 preliminar sigue no habilitado. P1 definitivo, compra y construcción siguen bloqueados.
