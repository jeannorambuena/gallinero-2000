# Criterios de habilitación P1 preliminar — Proyecto Gallinero Nacho

## Objetivo

Definir una checklist mínima para decidir si el proyecto puede pasar desde **P0 — Diagnóstico real** hacia una eventual **P1 preliminar**, sin autorizar compra de 500 pollonas, construcción ni inversión mayor.

## Diferencia entre P1 preliminar y P1 definitivo

**P1 preliminar** permite solo:

- diseño exploratorio;
- cotizaciones;
- validación técnica;
- comparación de alternativas;
- preparación de información para decidir.

**P1 preliminar NO permite:**

- comprar pollonas;
- construir;
- comprometer inversión mayor;
- cerrar presupuesto definitivo;
- calcular VAN, TIR, ROI o Payback definitivo.

**P1 definitivo** solo puede evaluarse después de cerrar P0 y completar diseño, CAPEX, flujo, mercado y riesgos.

## Criterios mínimos para habilitar P1 preliminar

1. Validación comercial inicial con clientes/canales y estimación de bandejas comprometidas.
2. Revisión legal/contable preliminar.
3. Croquis del terreno 19 x 7 m.
4. Alternativa constructiva preliminar.
5. Dimensionamiento preliminar de agua.
6. Dimensionamiento preliminar de energía solar.
7. Evaluación logística de acceso, descarga y acopio.
8. CAPEX preliminar por categorías.
9. Flujo de caja preliminar proyectado.
10. Criterios de no avance definidos.

## Criterios que bloquean P1 definitivo

- P0 todavía no está cerrado.
- Mercado para 130–135 bandejas/semana no validado.
- CAPEX total pendiente.
- Flujo de caja proyectado incompleto.

- Agua y energía sin dimensionamiento suficiente.

- Venta potencial adicional declarada todavía insuficiente.
