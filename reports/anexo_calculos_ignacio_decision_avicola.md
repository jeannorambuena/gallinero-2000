# Anexo de cálculos — decisión avícola Ignacio Moraga

Este anexo contiene las tablas de respaldo. Puede usar términos técnicos, pero se explican en lenguaje simple.

- **CAPEX:** inversión inicial necesaria para construir, equipar y comprar aves.
- **OPEX:** costo mensual de operación.
- **Payback:** meses estimados para recuperar la inversión con el resultado mensual preliminar.
- **Punto de equilibrio:** venta mínima necesaria para no perder.
